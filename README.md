## Key Features

### Botanical Classification Engine
* **Extensive Database:** A robust backend cataloging 200 uniquely classified flowers.
* **Advanced Multi-Parameter Filtering:** Users can seamlessly query the database based on highly specific traits, including color, petal shape, type, and symbolism.

### Authentication & Curation
* **Secure Login:** Integrated user authentication supporting both Google OAuth and custom OTP verification.
* **Personalized Collections:** Authenticated users can curate and save their own personal collections of favorite flowers directly to their profile.

### Immersive User Experience
* **Interactive UI:** Fluid animations and interactive elements powered by Framer Motion, delivering a polished, responsive frontend experience.
* **Complex System Design:** Architected to handle high-performance data querying while maintaining a clean, highly visual frontend encyclopedia.

---

## Tech Stack

### Frontend (Client)
* **Framework:** React
* **Animations:** Framer Motion
* **Deployment:** Vercel

### Backend (Server)
* **Runtime:** Node.js & Express.js
* **Authentication:** OTP Verification & Google OAuth
* **Deployment:** Render

### Database
* **Database:** MongoDB Atlas (M0 Cluster)
* **Architecture:** Custom botanical classification engine and schema design tailored for deep filtering.
